# Catalog snapshot

Generated by `pnpm eval:fixtures:catalog` from the live commercetools project.

Used as a reference when writing `evals/tests/retrieval.yaml` golden SKUs. Safe to commit: ids, SKUs, and names only — no credentials.

Golden SKUs are the products whose names match the query (coffee tables `GMCT-01` / `ADCT-01`, wine glass `CWG-01`, drinkware glasses/mugs, dining chairs). Pass them as a JSON string in YAML so Promptfoo does not explode the list into one test per SKU.
