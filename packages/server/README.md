# @commerce-ai-tool/server

Server-side API handlers (Next.js App Router and Express) for [Commerce AI Tool](https://github.com/tomasz-miller/commerce-ai-tool). Secrets stay on the host; the widget calls only `/api/commerce-ai/*`.

```bash
# React / Next.js host
pnpm add @commerce-ai-tool/react @commerce-ai-tool/server

# Angular host
pnpm add @commerce-ai-tool/angular @commerce-ai-tool/server
```

The `apps/demo-next` example in the GitHub repository is not an npm dependency.

Setup: [Getting started](https://github.com/tomasz-miller/commerce-ai-tool/blob/main/docs/GETTING-STARTED.md).
